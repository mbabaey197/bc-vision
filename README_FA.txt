BC Vision v1.1.0 - گیلاس آبی البرز

این نسخه، پایه تجاری محصول است و شامل موارد زیر می‌شود:
- مدیریت و نمایش زنده دوربین‌های RTSP و دوربین آزمایشی
- ورود امن، SQLite و ذخیره داده در ProgramData ویندوز
- سیستم لایسنس آفلاین با امضای دیجیتال Ed25519
- شناسه سخت‌افزاری دستگاه و پلن‌های Basic / Professional / Enterprise
- نسخه آزمایشی ۳۰ روزه و محدودیت ظرفیت دوربین بر اساس پلن
- خروجی CSV از ترددها و دریافت نسخه پشتیبان دیتابیس
- Installer و اسکریپت ساخت EXE با برند BC Vision

اجرا از سورس:
1) RUN_SOURCE.bat
2) مرورگر: http://127.0.0.1:8000/login
3) ورود اولیه: admin / 123456

صدور لایسنس توسعه:
python tools/generate_license.py --machine MACHINE_ID --customer "Customer" --plan professional --days 365 --output license.json
کلید خصوصی داخل tools/keys ساخته می‌شود و نباید در GitHub یا فایل مشتری قرار بگیرد.
فایل license_public_key.pem باید همراه برنامه مشتری Build شود.

نکته:
- OCR واقعی پلاک ایرانی هنوز به موتور پردازش اضافه نشده است.
- قبل از فروش، رمز اولیه را تغییر دهید و کلید خصوصی را در یک سیستم امن نگه دارید.
