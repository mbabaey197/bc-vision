# BC Vision

سامانه محلی و آفلاین مدیریت دوربین و پلاک‌خوانی خودرو با پشتیبانی از پلاک ایران.

نسخه مرجع پروژه فقط از فایل `VERSION` خوانده می‌شود. سورس قابل انتشار در ریشه Repository قرار دارد؛ پوشه‌های Backup، ZIPهای سورس و خروجی‌های Build نباید وارد Git شوند.

## قابلیت‌های اصلی

- نمایش زنده و مدیریت چند دوربین
- پردازش فایل ویدئویی و ثبت تردد
- تشخیص پلاک با مدل‌های ONNX و اجماع چندفریمی
- نمایش حدس‌های مدل برای بررسی و اصلاح اپراتور
- ذخیره تصویر خودرو و Crop پلاک
- گزارش‌گیری، فهرست مجاز/غیرمجاز و جست‌وجوی پلاک
- تاریخ و ساعت شمسی و ارقام فارسی
- SQLite با WAL، Migration و Backup اتمیک
- اجرای سرویس ویندوز بدون پنجره Console
- نصب کامل و به‌روزرسانی یک‌کلیکی با حفظ داده و مدل

## شروع توسعه

پیش‌نیاز رسمی Build و تست، Python 3.13 است.

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-test.txt
.venv\Scripts\python.exe -m pytest
```

برای اجرای سورس در ویندوز:

```text
RUN_SOURCE.bat
```

در اولین اجرا هیچ حساب یا رمز ثابتی ساخته نمی‌شود. صفحه راه‌اندازی، ایجاد مدیر اولیه با رمز انتخابی کاربر را اجباری می‌کند.

## مدل‌ها و موتور فعال

قرارداد دقیق Detector، OCR، Fallbackها، Hash مدل‌ها و مسیر فعال‌سازی موتور آزمایشی در [ANPR_ENGINE.md](ANPR_ENGINE.md) ثبت شده است.

## ساخت ویندوز

- `BUILD_SETUP_EXE.bat`: ساخت برنامه و Installer کامل
- `installer/BCVision_Update.iss`: ساخت Updater یک‌کلیکی برای نصب موجود
- `VERSION`: تنها مرجع شماره نسخه

داده‌ها و مدل‌ها خارج از پوشه نصب نگهداری می‌شوند تا نصب نسخه جدید آن‌ها را حذف نکند.

## امنیت انتشار

کلید خصوصی امضای لایسنس، رمز دوربین، دیتابیس واقعی، فایل `.env`، Log و داده مشتری نباید Commit شوند. کلید عمومی `license_public_key.pem` برای اعتبارسنجی لایسنس قابل انتشار است.
