# زیرساخت هوش مصنوعی BC Vision

این نسخه زیرساخت تشخیص پلاک و OCR را فعال می‌کند.

## تشخیص پلاک

- روش پایه و آفلاین با OpenCV بدون نیاز به مدل خارجی فعال است.
- استفاده از YOLO اختیاری است.
- برای فعال‌شدن YOLO باید بسته `ultralytics` نصب باشد.
- مدل آموزش‌دیده باید در مسیر `app/ai/models/plate.pt` قرار گیرد.
- در نبود مدل یا بسته Ultralytics، برنامه به‌صورت خودکار از OpenCV استفاده می‌کند.

## خواندن متن پلاک

- EasyOCR در صورت نصب‌شدن به‌صورت اختیاری استفاده می‌شود.
- Tesseract و بسته `pytesseract` مسیر جایگزین OCR هستند.
- در نبود موتورهای OCR، برنامه بدون توقف اجرا می‌شود اما متن پلاک استخراج نخواهد شد.

## وضعیت فعلی بسته

فایل مدل `plate.pt` داخل این بسته سورس وجود ندارد. برای افزایش دقت پلاک‌های ایران، مدل اختصاصی آموزش‌دیده و موتور OCR فارسی باید جداگانه نصب و پیکربندی شوند.
